3D models of the PicoZorro One TH board (referenced as ${KIPRJMOD}/3d/*.step)

core2350b.step, w5500-lite.step, microsd-breakout.step, gy-pcm5102.step, ptc-radial.step
  Part of this project, modelled with build123d (Apache-2.0). The board slabs, the M3 jack and F1 are
  drawn from the makers' dimensions and the measurements in ../README.md. No maker model exists:
  Waveshare's Core2350B wiki has a schematic and demo files only, WIZnet's WIZ850io page schematics
  only, the microSD and GY-PCM5102 breakouts have no maker, and KiCad's library has no model for the
  radial PTC footprint F1 uses (Fuse_Bourns_MF-RHT070 names a file KiCad does not ship).

KiCad library models built into them (KiCad 3D library, tag 10.0.6,
https://gitlab.com/kicad/libraries/kicad-packages3D)
  Connector_RJ.3dshapes/RJ45_Molex_9346520x_Horizontal.step      in w5500-lite.step
      shape stand-in for the module's HanRun HR961160C: KiCad's library has no HanRun model. The
      Molex 93465 is the same body class (tab-up magjack with LEDs, 16.2 x 25.4 x 14.1 against 16.1 x
      25.4 x 13.61); its springs sit behind the module edge, the HR961160C's at the front; it has no
      LEDs, so the HR961160C's two LED windows are added on its face
  Connector_Card.3dshapes/microSD_HC_Hirose_DM3AT-SF-PEJM5.step  in microsd-breakout.step
  Package_SO.3dshapes/TSSOP-20_4.4x6.5mm_P0.65mm.step            in gy-pcm5102.step (the PCM5102A)
